# Drift System

Enhance your FiveM drifting experience with adjustable gravity levels and point tracking.

## Features

- Adjustable gravity levels based on drift points
- Point tracking system for players

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start driftSystem` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Players will earn points while drifting
- Gravity levels will adjust based on the points earned

## Configuration

- Adjust gravity levels and points in the config.lua file
